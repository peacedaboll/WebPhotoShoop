# Демонстрация заданий 6 и 7

## Сохранённые версии

| Версия | Этап | Разница |
| --- | --- | --- |
| v0.1.0 | Задания 1–5 | Слои, кисть, текст, коррекция, обрезка, экспорт |
| v0.2.0 | Задание 6 | Дополнительно три цветовых эффекта и анализ защиты |
| v0.3.0 | Задание 7 | Дополнительно серверные учётные записи и сеансы |

Предыдущая версия не заменяется макетом. Она сохранена в Git и в локальном исходном архиве. Для параллельного запуска используйте отдельную папку, чтобы переключение версии не изменяло рабочий каталог и данные актуального приложения.

## Запуск предыдущей версии

Распакуйте WebPhotoShoop-v0.2.0.zip в отдельную папку. Выполните npm ci, npm run build. В PowerShell задайте `$env:PORT='3002'`, `$env:HOST='127.0.0.1'`, затем npm start. Откройте http://localhost:3002. Архив содержит исходники и lock-файл; установленные зависимости и пользовательские данные в него не входят.

Из Git тот же результат получается командами git archive --format=zip --output=previous.zip v0.2.0 и распаковкой. Для исходного состояния можно аналогично использовать v0.1.0. Эти команды не меняют текущую ветку.

## Запуск актуальной версии

В основной папке проекта выполните npm ci, npm run build, затем npm start. Если переменная PORT ранее изменялась в том же терминале, верните её к 3001. Откройте http://localhost:3001. Для изолированного локального показа используйте HOST=127.0.0.1. Обычная раздача по локальной сети сохранена, однако настоящие пароли следует передавать только через HTTPS.

## Показ работающего редактора

1. В обеих версиях нажмите «Попробовать на демо», выберите слой «Пейзаж».
2. Покажите кисть или текст, отмену и экспорт: обе версии действительно выполняют операции.
3. В v0.2 примените «Чёрно-белый», покажите историю, отмените и повторите действие. При сравнении с v0.1 этой панели ещё нет.
4. В v0.3 нажмите «Войти» → «Создать учётную запись». Используйте искусственный email и новую тестовую парольную фразу, не настоящий пароль от другого сайта.
5. Покажите email в шапке, перезагрузите страницу, убедитесь, что сеанс сохранился. Работа редактора при перезагрузке сбрасывается — учётная запись пока не сохраняет изображения.
6. Выйдите, попробуйте неверный пароль, затем войдите правильно. В v0.2 учётных записей и этих серверных маршрутов нет.
7. Покажите CHANGELOG.md с отдельными записями 0.1, 0.2, 0.3, Git log и актуальный коммит GitHub. Теоретические отчёты покажите отдельно от демонстрации сайта.
