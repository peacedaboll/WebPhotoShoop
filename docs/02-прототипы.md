# Прототипы интерфейса

Открыть `docs/prototypes/index.html` в браузере. Девять изображений — макеты целевого интерфейса, отдельно от снимков реального приложения в `docs/verification`. Исходник построения — `scripts/make_visuals.py`.

| Макет | Состояние | Реакция и назначение |
| --- | --- | --- |
| 01-start | Первый запуск | Открытие изображения или демо; отмена недоступна |
| 02-editor | Изображение открыто | Холст, видимые слои, параметры выбранного слоя |
| 03-new | Новый холст | Ввод размеров, предупреждение о замене работы |
| 04-brush | Кисть активна | Выделенная кнопка, цвет, размер, курсор на холсте |
| 05-export | Параметры экспорта | Формат, имя, качество, состав видимых слоёв |
| 06-loading | Выполнение операции | Целевой прогресс по этапам и заблокированная кнопка |
| 07-error | Отказ загрузки | Причина, повтор выбора и возврат к работе |
| 08-crop | Уточнение по заданию 4 | Целевая рамка и сетка обрезки |
| 09-adjust | Уточнение по заданию 4 | Раздельные регуляторы цвета и подтверждение |

В первичном прототипе определены вход в приложение и основные действия. Подробные макеты добавляют состояния кнопок, активного инструмента, ожидания и ошибки. Уточнение итогового прототипа включает обрезку и коррекцию.

## Отличия версии 0.1 от целевого интерфейса

- Загрузка и экспорт показывают индикатор ожидания без точного процента. У Canvas нет достоверного непрерывного прогресса кодирования; проценты не имитируются.
- Ошибка загрузки выводится в строке состояния. Ошибка размера холста также видна внутри диалога.
- Обрезка выполняется вводом координат; интерактивная рамка и сетка пока относятся к макету.
- История, слои, экспорт и коррекция реализованы; отдельные декоративные элементы макетов могут отличаться.
- Число слоёв на макете иллюстрирует возможное состояние и не является результатом теста.

## Визуальные состояния элементов

Обычная кнопка — тёмная с тонкой границей. Наведение повышает контраст. Активный инструмент выделен светло-зелёным. Недоступная кнопка приглушена. Фокус клавиатуры обозначается контуром. При долгой операции кнопка экспорта блокируется, строка состояния объясняет текущий шаг. Ошибка не должна заменяться непонятным техническим кодом.
